## Q1. Stack Using Array

### Implemented
- PUSH()
- POP()
- PEEK()
- DISPLAY()
- Overflow and Underflow handling

### Complexity

| Operation | Time |
|---|---|
| PUSH | O(1) |
| POP | O(1) |
| PEEK | O(1) |
| DISPLAY | O(n) |

## Q2. Circular Queue Using Array

### Implemented
- ENQUEUE()
- DEQUEUE()
- FRONT()
- DISPLAY()
- Full and Empty queue handling

### Complexity

| Operation | Time |
|---|---|
| ENQUEUE | O(1) |
| DEQUEUE | O(1) |
| FRONT | O(1) |
| DISPLAY | O(n) |

### Circular Queue vs Linear Queue

- Circular Queue reuses empty spaces.
- It avoids unnecessary space wastage.
- ENQUEUE and DEQUEUE take O(1) time.
